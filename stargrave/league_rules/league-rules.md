# League Specific Rules

## Playing the Game

All of the rules in this section are official rules, however this details the specific optional rules being used for this campaign.

### Table Setup

The side hustle expansion is being used which provides secret missions for each mission. Because of the added complexity and because of the specialty terrain required for a lot of the missions, we will only be playing the standard mission with side hustle.

When your opponent is allocated for the month you will also be sent a secret mission. Don't look at your secret mission yet (although if you do it won't be the end of the world).

These expansions use three *side hustle markers*. A 'pylon', a 'pit' and a 'destroyed robot'. These will be supplied by Declan along with normal loot markers.

Because of these expansions, the table setup is different from a normal stargrave game. Follow the steps below:

1. Set up the terrain in a mutually agreeable manner. It should never be possible to draw line of sight from one table edge to the other along the ground. Generally models shouldn't be able to draw unobstructed line of sight for more than a foot or two. 
4. Placing loot and side hustle markers:
    1. Roll to determine if the 'central' loot token will be data (1-10) or physical (11-20). This will be used in the next step.
    2. Take the 'central' loot token and the 3 side hustle markers (pylon, pit and robot). Place these in a line running along the center of the table, randomly allocating their order. They should be roughly equidistant between each other and the table edge.  
    3. Move each of the side hustle markers (not the 'central' loot token) d3" in a random direction
2. Both players roll a dice, the highest selects the table edge.
    * For 2x2 table, choose starting corner, the other player gets the opposite corner
    * For 3x3, choose starting edge 
3. Players look at their secret mission cards
4. First player deploys all their models
    * For 2x2 table, deploy within 5" of corner
    * For 3x3 table, deploy within 2" of the starting edge and at least 6" away from any other edge.
    4. The player who deployed their figures *last* places a loot token. The token may be of either type, placed in their opponent's half of the table and at least 4" away from any other loot token or side hustle marker.
    5. The other player then places a loot token, which may also be of either type, following the same criteria as the point above.
5. Start playing! Begin by rolling for initiative (Quick Reference -> Turn Order -> Initiative)

### During Missions

Remember the following during missions!

* Take a photo!
* Everytime a loot token is unlocked roll a d20. On a 10+ a random encounter appears. Roll on your table's Random Encounter Table (see below). Randomly determine where on the table edge it appears.
* Crews gain experience for completing in-game achievements. *Max 300* exp per game. Track these during the game so you don't forget.

| Exp | Achievement                                                                                                                                         |
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| +30 | Each game played with crew                                                                                                                          |
| +30 | If crew had figure reduced to 0 health                                                                                                              |
| +20 | For each loot token unlocked by crew                                                                                                                |
| +10 | For each power successfully activated by captain or first mate *max 100* (excluding poewrs that unlock loot tokens, then you just get above reward) |
| +10 | For each member of rival crew reduced to 0 health *max 40*                                                                                          |
| +5  | For each uncontrolled creature reduced to 0 health *max 20* (excluding creatures that give reward experience due to scenario/secret missions)       |

### Game Ends

The game ends when:

* All loot tokens have left the table
* If only one player has figures left on the table
  * Remember you can voluntarily move figures off the edge of the table to leave!

### Post Mission

For taking a part in a mission with the side hustle expansion, all crews get an additional 50 credits at the end of the mission, in addition to all other rewards.

## Random Encounters Table

All players who own a table with terrain should create a random encounter chart to go with that terrain. To create a random encounter chart simply pick a number of creatures from the Bestiary that correspond to painted figures you have and put them in a table. 

When an encounter appears roll a dice to randomly select an encounter. The dice you roll depends on how many creatures are in the encounter table. I'd recommend anywhere from 6 to 20 entries in the table.

When choosing painted figures for Stargrave Bestiary entries, I've found this list at Must Contain Minis(https://mustcontainminis.com/2021/04/stargrave-creatures-and-aliens-what-do-i-need.html) to be useful. However feel free to be liberal with counts-as. For example if you were looking for a Horat, a snow troll could easily be used instead of a woolly rhinoceros mini.

If you need some minis for encounters ask Declan as he has a bunch he can loan out!

For example, a sample encounter table could look like the following:
